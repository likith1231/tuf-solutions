# For loops

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Things to Know in C++/Java/Python or any language | **Difficulty:** Easy

## Approach
Use a standard for loop to iterate from 1 to N, collecting or printing each value in sequence. The method builds a list of integers representing the loop output, demonstrating initialization, condition checking, and increment steps of a for loop.

## Complexity
- Time: O(N)
- Space: O(N)
