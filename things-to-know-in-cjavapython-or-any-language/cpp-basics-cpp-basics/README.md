# Cpp Basics

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Things to Know in C++/Java/Python or any language | **Difficulty:** Easy

## Approach
Since this topic covers fundamental language basics (data types, variables, arithmetic operations, conditionals, loops, and basic I/O), the solution demonstrates these core concepts in Java. A static method `demonstrateBasics` showcases variable declarations of different primitive types, arithmetic operations, conditional statements, loop constructs, and string handling, which are the foundational building blocks needed before tackling more advanced DSA problems.

## Complexity
- Time: O(1)
- Space: O(1)
