# Theory with examples

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Things to Know in C++/Java/Python or any language | **Difficulty:** Easy

## Approach
This problem covers foundational programming theory concepts needed before diving into DSA: data types, variables, operators, control flow, loops, arrays, strings, functions (including recursion), and basic input/output handling. The solution demonstrates each of these core language features with small, self-contained example methods, and a main method that exercises them to show how they work in practice.

## Complexity
- Time: O(N) for array/string traversal examples, O(1) for arithmetic and control-flow examples, O(N) for recursive factorial
- Space: O(1) for primitive examples, O(N) for array storage, O(N) recursion stack for factorial
