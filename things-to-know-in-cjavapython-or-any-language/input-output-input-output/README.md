# Input Output

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Things to Know in C++/Java/Python or any language | **Difficulty:** Easy

## Approach
Read input values using a Scanner (or BufferedReader) and print output using System.out. This demonstrates basic input/output handling in Java: reading integers, strings, and printing results in the required format.

## Complexity
- Time: O(1)
- Space: O(1)
