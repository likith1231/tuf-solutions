# What are arrays, strings?

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Things to Know in C++/Java/Python or any language | **Difficulty:** Easy

## Approach
Demonstrate the basic concepts of arrays and strings in Java. An array is a fixed-size, contiguous collection of elements of the same type, accessed via indices. A string is a sequence of characters, represented in Java as an immutable object of the String class (internally backed by a char array). The solution shows declaration, initialization, traversal, and basic operations like finding the sum of array elements and reversing a string, illustrating how these fundamental data structures store and manipulate data.

## Complexity
- Time: O(N)
- Space: O(N)
