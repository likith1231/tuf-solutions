# Switch Case

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Things to Know in C++/Java/Python or any language | **Difficulty:** Easy

## Approach
Use a switch-case statement to map an integer input (e.g., day number 1-7) to a corresponding output (e.g., day name). The switch statement evaluates the input value and executes the matching case block, providing a clear and efficient way to handle multiple discrete conditions compared to multiple if-else statements.

## Complexity
- Time: O(1)
- Space: O(1)
