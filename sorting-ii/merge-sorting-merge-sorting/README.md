# Merge Sorting

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Sorting-II | **Difficulty:** Medium

## Approach
Implement classic Merge Sort: recursively divide the array into two halves until each sub-array has a single element, then merge the sorted halves back together using an auxiliary array to combine elements in sorted order.

## Complexity
- Time: O(N log N)
- Space: O(N)
