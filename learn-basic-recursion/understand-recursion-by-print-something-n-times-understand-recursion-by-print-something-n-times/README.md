# Understand recursion by print something N times

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Learn Basic Recursion | **Difficulty:** Easy

## Approach
Define a recursive method that takes a counter and N. If the counter exceeds N, return (base case). Otherwise, print the desired statement and call the function recursively with counter+1. This demonstrates how recursion can replace a loop to repeat an action N times.

## Complexity
- Time: O(N)
- Space: O(N)
