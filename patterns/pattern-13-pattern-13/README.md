# Pattern 13

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Patterns | **Difficulty:** Easy

## Approach
Use a counter variable starting at 1, iterate through rows from 1 to n, and for each row print 'i' numbers using the counter, incrementing it after each print, then move to a new line.

## Complexity
- Time: O(N^2)
- Space: O(1)
