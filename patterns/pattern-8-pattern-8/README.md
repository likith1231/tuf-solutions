# Pattern 8

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Patterns | **Difficulty:** Easy

## Approach
Print an inverted pyramid of stars. For each row i from 0 to n-1, print i spaces followed by (2*(n-i)-1) stars, using nested loops to build the pattern row by row.

## Complexity
- Time: O(N^2)
- Space: O(1)
