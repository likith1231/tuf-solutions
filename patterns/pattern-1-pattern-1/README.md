# Pattern 1

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Patterns | **Difficulty:** Easy

## Approach
Iterate rows from 1 to n, and in each row iterate columns from 1 to n, printing a star for each column, then move to a new line after each row completes. This forms a square pattern of stars.

## Complexity
- Time: O(N^2)
- Space: O(1)
