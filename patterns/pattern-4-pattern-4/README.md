# Pattern 4

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Patterns | **Difficulty:** Easy

## Approach
Use two nested loops where the outer loop controls the row number from 1 to n, and the inner loop runs from 1 to the current row number, printing the current row number (i) as the value in each iteration. Append a newline after each row.

## Complexity
- Time: O(N^2)
- Space: O(1)
