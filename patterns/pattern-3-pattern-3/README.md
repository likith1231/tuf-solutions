# Pattern 3

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Patterns | **Difficulty:** Easy

## Approach
Iterate rows from 1 to n, and in each row print numbers from 1 to the current row number, separated by spaces, then move to a new line.

## Complexity
- Time: O(N^2)
- Space: O(1)
