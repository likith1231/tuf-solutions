# Pattern 2

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Patterns | **Difficulty:** Easy

## Approach
Iterate through rows from 1 to N. For each row i, print i stars followed by a newline, forming a right-angled triangle pattern.

## Complexity
- Time: O(N^2)
- Space: O(1)
