# Pattern 20

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Patterns | **Difficulty:** Medium

## Approach
For a given size n, print an n x n grid where a '*' is printed at position (i, j) if j equals i (the main diagonal) or j equals n-1-i (the anti-diagonal); otherwise a space is printed. This forms an X shape.

## Complexity
- Time: O(N^2)
- Space: O(1)
