# Pattern 10

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Patterns | **Difficulty:** Easy

## Approach
Print an upward right-angled triangle of stars from 1 to n rows, followed immediately by a downward right-angled triangle of stars from n to 1 rows, creating a combined pattern (increasing then decreasing star counts). This is done using two nested loops: the outer loop controls the row count, and the inner loop prints the stars for that row.

## Complexity
- Time: O(N^2)
- Space: O(1)
