# Pattern 7

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Patterns | **Difficulty:** Easy

## Approach
For each row i from 1 to n, print (n-i) spaces followed by (2*i-1) stars, then move to the next line. This creates a pyramid pattern where each row has increasing stars centered using leading spaces.

## Complexity
- Time: O(N^2)
- Space: O(1)
