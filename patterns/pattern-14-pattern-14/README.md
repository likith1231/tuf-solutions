# Pattern 14

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Patterns | **Difficulty:** Easy

## Approach
For each row i from 1 to n, print numbers from 1 to i separated by spaces, forming a right-angled triangle pattern where each row contains increasing sequence of numbers starting from 1 up to the row number.

## Complexity
- Time: O(N^2)
- Space: O(1)
