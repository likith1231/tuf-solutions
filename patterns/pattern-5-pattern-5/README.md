# Pattern 5

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Patterns | **Difficulty:** Easy

## Approach
Print n rows where the i-th row contains (n - i + 1) stars, i.e., the number of stars decreases from n down to 1, forming an inverted right triangle.

## Complexity
- Time: O(N^2)
- Space: O(1)
