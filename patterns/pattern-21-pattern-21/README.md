# Pattern 21

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Patterns | **Difficulty:** Medium

## Approach
Print an n x n grid where a character is printed as '*' if it lies on the border of the square (first row, last row, first column, or last column), otherwise print a space, creating a hollow square pattern.

## Complexity
- Time: O(N^2)
- Space: O(1)
