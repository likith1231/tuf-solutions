# Pattern 6

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Patterns | **Difficulty:** Easy

## Approach
For each row i from 1 to n, print numbers from 1 to i separated by spaces, then move to a new line. This creates a right triangle pattern where the row number determines how many sequential numbers are printed.

## Complexity
- Time: O(N^2)
- Space: O(1)
