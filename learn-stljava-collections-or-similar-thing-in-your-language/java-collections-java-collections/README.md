# Java Collections

**Source:** https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z | **Topic:** Learn STL/Java-Collections or similar thing in your language | **Difficulty:** Easy

## Approach
Demonstrate core Java Collections Framework classes by reading a list of integers from input, storing them in an ArrayList, removing duplicates with a HashSet, counting frequencies with a HashMap, and producing a sorted list of unique elements using Collections.sort. This showcases how to use List, Set, and Map interfaces together to solve a typical data manipulation task.

## Complexity
- Time: O(N log N)
- Space: O(N)
